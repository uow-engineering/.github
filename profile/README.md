# UoW Engineering

Mechatronics projects, labs and tools.

**Where things live**
- **GitHub:** firmware and electronics (schematics, PCBs). Each repo's README links to its SharePoint folder.
- **SharePoint:** CAD, fabrication files (.beam, .3mf), docs, images, assembly guides and presentations. Each SharePoint project has an `Embedded.url` linking back to its repo.

**Starting a project?** Use [template-arduino-simple](https://github.com/uow-engineering/template-arduino-simple).

**Contributing?** Start with [CONTRIBUTING.md](https://github.com/uow-engineering/.github/blob/main/CONTRIBUTING.md). It's short.
